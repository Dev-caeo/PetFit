# 🐾 PetFit - Controle de Alimentação Pet

Aplicação web desenvolvida com foco em prototipagem rápida, integração de ferramentas de IA (Google AI / Gemini) e experiência do usuário (UX/UI).

## 📌 Sobre o projeto
O PetFit é um sistema para controle alimentar de pets, permitindo acompanhar dados importantes de forma visual e intuitiva. A proposta é ajudar tutores a monitorar a saúde e a rotina nutricional dos animais de forma simples.

## 🚀 Funcionalidades
- Controle de calorias consumidas e gastas
- Indicador visual de alimentação
- Cálculo de índice corporal do pet (IMC)
- Sistema de autenticação e gestão de perfis

## 🧠 Tecnologias e IA
- **Frontend / Prototipagem:** TypeScript, Figma, Material Design 3
- **Inteligência Artificial:** Uso de ferramentas do Google AI Lab no fluxo de desenvolvimento e estruturação do produto
- **Backend & Auth:** Firebase
